# Telegram Channel Cloner GUI

Графическое приложение для клонирования Telegram-каналов с поддержкой мультиаккаунтинга, прокси и гибкой настройки оформления.

## Возможности

- **GUI-интерфейс** — удобное desktop-приложение на PyQt6 с тёмной/светлой/пользовательской темой
- **Мультиаккаунтинг** — храните несколько аккаунтов, каждый работает независимо
- **Прокси** — настраивайте отдельный прокси для каждого аккаунта (HTTP / HTTPS / SOCKS4 / SOCKS5)
- **Выбор чатов** — после авторизации выводится список каналов/супергрупп; выбирается 1 источник и несколько целей
- **Клонирование** — перезаливка медиа (фото, видео, документы, стикеры, GIF, голосовые, видео-заметки) с сохранением порядка
- **Промо-текст** — автоматическое добавление ссылки на бота и хэштегов к каждому посту
- **Очистка цели** — перед клонированием можно очистить целевой канал
- **Задержки** — настраиваемые минимальная/максимальная задержка между постами
- **Лимит сообщений** — возможность ограничить количество постов
- **Прогресс и лог** — наглядный прогресс-бар и детальный лог операций
- **Гибкие настройки** — выбор темы, акцентного цвета, фона, цвета текста, размера шрифта
- **Интерактивная авторизация** — вход по телефону + код + 2FA прямо из GUI
- **Контакты разработчика** — `@doker420`, [GitHub](https://github.com/doker420)

## Установка

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/doker420/telegram-cloner-gui.git
cd telegram-cloner-gui

# 2. Создайте виртуальное окружение
python -m venv venv

# Windows:
venv\Scripts\activate

# Linux / macOS:
source venv/bin/activate

# 3. Установите зависимости
pip install -r requirements.txt
```

## Настройка

1. Запустите приложение:
   ```bash
   python app.py
   ```

2. Перейдите на вкладку **⚙️ Настройки** и укажите:
   - `API ID` и `API Hash` — получить на [my.telegram.org](https://my.telegram.org)
   - Ссылка на бота
   - Хэштеги
   - Задержки по умолчанию

3. Перейдите на вкладку **👥 Аккаунты** → **➕ Добавить аккаунт**:
   - Введите номер телефона
   - Введите код из Telegram
   - При необходимости введите пароль 2FA
   - Аккаунт сохранится в `data/accounts.json`, сессия — в папке `sessions/`

4. Для каждого аккаунта можно настроить прокси:
   - Выберите аккаунт в таблице
   - Нажмите **Прокси**
   - Введите в формате: `socks5://user:pass@host:port` или `http://host:port`

## Использование

1. **Чаты** — выберите аккаунт, загрузите список чатов, переместите один чат в **Источник** и несколько в **Цели**, нажмите **💾 Сохранить выбор**

2. **Клонирование** — настройте параметры:
   - Очистить цель перед клонированием
   - Добавить промо-текст
   - Промо-текст и хэштеги
   - Задержка между постами
   - Лимит сообщений

3. Нажмите **🚀 Запустить клонирование**

4. Для остановки нажмите **⛔ Остановить**

## Безопасность

- **Не публикуйте** папку `sessions/` и файл `data/accounts.json` — они содержат данные для входа
- Рекомендуется добавить `sessions/`, `data/accounts.json`, `.env` в `.gitignore`
- Для продакшена используйте переменные окружения вместо хранения API-ключей в конфигах
